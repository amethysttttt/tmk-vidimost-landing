# Как разместить лендинг на своём сервере (вместо прямого Vercel)

Зачем: у части провайдеров адреса Vercel не открываются. Если сайт отдаёт сервер компании в Казахстане,
посетитель к Vercel не обращается. Форма заявок продолжает работать: nginx пересылает её на функцию Vercel со своего сервера.

## 1. DNS (вместо CNAME на Vercel)
Для ai.tmk-technohorizon.kz добавить **A-запись** на IP сервера, где уже работает tmk-technohorizon.kz:

| Тип | Имя | Значение |
|---|---|---|
| A | `ai` | `185.146.3.124` |

CNAME на vercel-dns и TXT `_vercel` в этом варианте **не нужны**.

## 2. Файлы сайта
```
sudo git clone https://github.com/amethysttttt/tmk-vidimost-landing.git /var/www/ai.tmk-technohorizon.kz
```
Обновление после изменений: `cd /var/www/ai.tmk-technohorizon.kz && sudo git pull`

## 3. nginx
```
sudo cp /var/www/ai.tmk-technohorizon.kz/deploy/nginx-ai.tmk-technohorizon.kz.conf /etc/nginx/sites-available/ai.tmk-technohorizon.kz
sudo ln -s /etc/nginx/sites-available/ai.tmk-technohorizon.kz /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

## 4. HTTPS
```
sudo certbot --nginx -d ai.tmk-technohorizon.kz
```

## 5. Проверка
- https://ai.tmk-technohorizon.kz открывается, /spasibo и /privacy открываются без .html
- `curl -X POST https://ai.tmk-technohorizon.kz/api/lead -H 'Content-Type: application/json' -H 'Accept: application/json' -d '{"name":"x"}'` отвечает `{"ok": false, "error": "validation"}` - значит форма доходит до функции

После этого напишите Адильжану - он переведёт ссылки, sitemap и аналитику на новый адрес.
